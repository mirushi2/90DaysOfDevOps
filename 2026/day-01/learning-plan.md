# 90 Days of DevOps Learning Plan

## About Me
- Current Level: Working Professional (Software Engineer)
- Goal: Transition from AI knowledge to practical DevOps and Cloud Engineering skills.

## My Understanding of DevOps & Cloud Engineering
DevOps is a culture and set of practices that improve collaboration between development and operations teams to deliver software faster, more reliably, and with higher quality. Cloud Engineering focuses on designing, deploying, and managing scalable infrastructure and applications using cloud platforms such as AWS, Azure, or GCP.

## Why I Am Learning DevOps & Cloud
I want to understand the complete software delivery lifecycle beyond application development. By learning DevOps and Cloud technologies, I aim to automate deployments, manage infrastructure efficiently, and become a well-rounded engineer capable of building and operating production-grade systems.

## Where I Want to Reach
By the end of these 90 days, I want to confidently build, deploy, and manage applications using modern DevOps practices and cloud-native tools.

## My 90-Day Goals
1. Build strong Linux, Git, and scripting fundamentals.
2. Create and automate CI/CD pipelines using industry-standard tools.
3. Deploy and manage a production-style application on Kubernetes in the cloud.

## Core DevOps Skills I Want to Build
1. Linux Administration and Troubleshooting
2. CI/CD Pipeline Design and Automation
3. Docker and Kubernetes Deployment & Debugging

## Weekly Time Budget
- Weekdays: 2 to 2.5 hours per day
- Weekends: 4 to 6 hours per day
- Total: Approximately 18 to 22 hours per week

## Consistency Plan
- Study every day without skipping.
- Complete and document one practical task daily.
- Maintain notes and GitHub commits throughout the challenge.
- Share weekly progress updates on LinkedIn.

## Commitment
I commit to completing the #90DaysOfDevOps challenge with discipline, continuous learning, and hands-on practice. My objective is to build practical DevOps and Cloud skills that can be applied in real-world projects and advance my engineering career.
